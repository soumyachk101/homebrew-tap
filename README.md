# soumyachk101/homebrew-tap

Official Homebrew Tap for [Ensembyte](https://ensembyte.vercel.app).

## Installation

To install Ensembyte via Homebrew:

```bash
brew install soumyachk101/tap/ensembyte
```

Or tap first:

```bash
brew tap soumyachk101/tap
brew install --cask ensembyte
```

## Update

```bash
brew upgrade ensembyte
```
